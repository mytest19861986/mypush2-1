# Project Context — Hami Card

## ۱. مشخصات کلان پروژه
- **نام سامانه**: Hami Card (حامی کارت)
- **هدف**: پلتفرم جامع SaaS حوزه خدمات درمانی، سلامت و تخفیف پزشکی.
- **ماژول‌های کلیدی**:
  - کاربران و بیماران (خرید اشتراک، مشاهده مراکز، دریافت کد تخفیف)
  - پزشکان و متخصصان (ثبت تعرفه، احراز بیماران، ثبت خدمات)
  - مراکز درمانی و کلینیک‌ها
  - همکاران و نمایندگان فروش (سیستم ارجاع و کمیسیون)
  - طرح‌های تخفیف و اشتراک
  - مدیریت نقش‌ها و دسترسی‌های پیشرفته RBAC
