# Hami Card V2 - Server Smoke Test / تست سریع سرور

بعد از Deployment این چک لیست را روی دامنه Production اجرا کنید. هدف فقط اطمینان سریع از سلامت مسیرهای اصلی است.

## Checklist

- [ ] **Auth:** ورود، دریافت اطلاعات کاربر، Refresh session و Logout بررسی شد.
- [ ] **User panel:** داشبورد کاربر، پروفایل، طرح ها و قراردادهای کاربر باز می شوند.
- [ ] **Doctor panel:** داشبورد پزشک، پروفایل، بیماران و قراردادهای پزشک باز می شوند.
- [ ] **Agent panel:** داشبورد نماینده، مشتریان فروش، مدارک و کمیسیون ها باز می شوند.
- [ ] **Admin panel:** داشبورد ادمین، کاربران، پزشکان، نمایندگان، نقش ها و لاگ ها باز می شوند.
- [ ] **Upload/download:** آپلود فایل مجاز و دانلود فایل های ثبت شده بدون خطای دسترسی کار می کند.
- [ ] **Financial/commission pages:** صفحات مالی، تراکنش ها، کمیسیون ها و تسویه ها بدون خطای 500 باز می شوند.
- [ ] **Public doctors directory:** مسیر عمومی `/doctors` لیست پزشکان و فیلترها را نمایش می دهد.
- [ ] **Cache/service worker:** بعد از Hard Refresh یا پاک کردن Cache نسخه جدید دیده می شود.
- [ ] **Server health:** `pm2 status` پایدار است و `pm2 logs hami-card-v2` خطای تکرارشونده ندارد.
