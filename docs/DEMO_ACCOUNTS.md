# آماده‌سازی حساب‌ها و داده‌های دمو - Hami Card V2

## 1. هدف

این سند برای آماده‌سازی حساب‌های تست و داده‌های امن قبل از ارائه دمو به کارفرما استفاده می‌شود. هدف این است که جلسه دمو بدون نمایش اطلاعات واقعی، رمزها، توکن‌ها، شماره‌های خصوصی یا مدارک حساس برگزار شود و همه مسیرهای اصلی سامانه با داده‌های کنترل‌شده و قابل نمایش بررسی شوند.

## 3. داده‌های مورد نیاز برای دمو

قبل از جلسه دمو، وجود حداقل داده‌های زیر بررسی شود:

- حداقل یک پلن فعال برای کاربر
- حداقل یک پزشک تاییدشده با تصویر پروفایل
- حداقل یک همکار فروش با پروفایل تکمیل‌شده
- حداقل یک مشتری فروش در وضعیت‌های متفاوت
- حداقل یک رکورد ویزیت
- حداقل یک رکورد کمیسیون
- حداقل یک رکورد کیف پول یا تسویه، در صورت فعال بودن این بخش در محیط دمو

## 4. قوانین ایمنی

- هرگز از کد ملی واقعی مشتریان در دمو استفاده نشود.
- هرگز مدارک آپلودشده واقعی نمایش داده نشود.
- هرگز credential واقعی، رمز، توکن، کلید API یا اطلاعات محرمانه commit نشود.
- فقط از داده‌های تست و حساب‌های مخصوص دمو استفاده شود.
- قبل از جلسه، صفحات شامل اطلاعات حساس یا فایل‌های محیطی باز نباشند.

## 5. چک‌لیست قبل از دمو

- ورود به سامانه کار می‌کند.
- تصویر پزشک درست نمایش داده می‌شود.
- صفحه عمومی لیست پزشکان باز می‌شود.
- صفحات مالی/کمیسیون در پنل ادمین load می‌شوند.
- صفحه مشتریان همکار فروش load می‌شود.
- خروج از حساب کاربری کار می‌کند.
