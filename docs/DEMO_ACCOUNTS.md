# آماده‌سازی حساب‌ها و داده‌های دمو - Hami Card V2

## 1. هدف

این سند برای آماده‌سازی حساب‌های دمو و داده‌های امن پیش از ارائه به کارفرما استفاده می‌شود. هدف این است که در جلسه دمو، مسیرهای اصلی سامانه با داده‌های تست و قابل نمایش بررسی شوند، بدون اینکه رمز عبور واقعی، توکن، کد ملی واقعی، شماره خصوصی، مدرک حساس یا اطلاعات محرمانه نمایش داده شود.

## 3. داده‌های مورد نیاز برای دمو

پیش از جلسه دمو، وجود حداقل داده‌های زیر در محیط تست بررسی شود:

- حداقل یک پلن فعال برای کاربر
- حداقل یک پزشک تاییدشده با تصویر پروفایل
- حداقل یک همکار فروش با پروفایل تکمیل‌شده
- حداقل یک مشتری فروش در وضعیت‌های متفاوت
- حداقل یک رکورد ویزیت
- حداقل یک رکورد کمیسیون
- حداقل یک رکورد کیف پول یا تسویه، در صورتی که این بخش در محیط دمو فعال است

## 4. قوانین ایمنی

- هرگز از کد ملی واقعی مشتریان در دمو استفاده نشود.
- هرگز مدارک آپلودشده واقعی نمایش داده نشود.
- هرگز credential واقعی، رمز، توکن، کلید API یا اطلاعات محرمانه commit نشود.
- فقط از داده‌های تست و حساب‌های مخصوص دمو استفاده شود.
- پیش از ارائه، مطمئن شوید صفحه‌ای شامل لاگ حساس، فایل محیطی، تنظیمات سرور یا secret باز نیست.

## 5. چک‌لیست پیش از دمو

- ورود به سامانه کار می‌کند.
- تصویر پزشک درست نمایش داده می‌شود.
- لیست عمومی پزشکان باز می‌شود.
- صفحات مالی و کمیسیون در پنل ادمین load می‌شوند.
- صفحه مشتریان همکار فروش load می‌شود.
- خروج از حساب کاربری کار می‌کند.
